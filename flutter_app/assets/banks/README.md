# Logos de bancos y billeteras (opcional)

Por defecto Alvea muestra una insignia con los colores de cada entidad (`lib/ui/banks.dart`): los
logotipos oficiales son marcas registradas y no se distribuyen con la app.

Si tienes permiso para usar un logo, guárdalo aquí como `<id>.png` (cuadrado, ~128 px; el `id` es el
de `bankBrands`, p. ej. `nequi.png`) y añade ese id a `bankLogoAssets` en `lib/ui/banks.dart`.
